Python Toolkit – PLP Week 8

Project Overview

The Python Toolkit is a simple command-line application that combines different useful tools in one program. It allows users to select and run tools from a menu.

What My Toolkit Does

This toolkit provides different tools to help users perform simple tasks using Python.

- Displays a menu of available tools.
- Allows users to select a tool.
- Runs the selected tool.
- Checks invalid menu choices.
- Displays error messages for incorrect inputs.

Project Files

The project contains the following files:

- "toolkit.py" – Main Python program.
- "toolkit_plan.txt" – Project planning document.
- "screenshots/" – Folder containing screenshots of the menu, invalid choice, and each tool running.
- "README.md" – Project documentation.

Requirements

- Python 3 installed.
- Visual Studio Code or another code editor.
- A computer with a terminal or command prompt.

How to Run the Toolkit

1. Open the project folder in Visual Studio Code.
2. Open the terminal.
3. Make sure you are inside the project folder.
4. Run the following command:

python toolkit.py

5. The menu will appear.
6. Enter the number of the tool you want to use.
7. Follow the instructions displayed on the screen.

Screenshots

The screenshots folder contains:

- The toolkit menu.
- An invalid menu choice.
- Each tool running successfully.

Project Reflection

Testing helped me understand how to control program flow and handle errors. This project improved my problem-solving and Python programming skills. If I had one more week, I would add more useful tools and improve the menu design.
